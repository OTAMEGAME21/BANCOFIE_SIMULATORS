# Pruebas manuales recomendadas

## Página pública y acceso
- [ ] Abrir `index.html`: debe mostrarse la página pública.
- [ ] Confirmar que no aparecen opciones de simuladores, historial ni parámetros.
- [ ] Probar navegación por Inicio, Información, Productos y Servicios.
- [ ] Abrir el acceso desde el encabezado y desde el banner inferior.
- [ ] Confirmar que la contraseña aparece oculta al escribir.
- [ ] Probar el botón de ojo para mostrar y volver a ocultar la contraseña.
- [ ] Introducir credenciales incorrectas: debe mostrar un mensaje y no abrir el área privada.
- [ ] Introducir usuario `JhonatanChoqueFie1` y contraseña `JACRFIE1`: debe entrar y mostrar “Administrador”.
- [ ] Marcar “Recordar usuario”, cerrar sesión y verificar que solo el usuario se conserva.
- [ ] Confirmar que la contraseña no se conserva al cerrar o recargar.
- [ ] Cerrar sesión: debe volver al inicio público y ocultar las herramientas privadas.
- [ ] Intentar abrir una vista privada sin sesión: debe solicitar inicio de sesión.

## Plan de pagos
- [ ] Abrir el simulador de plan de pagos después de iniciar sesión.
- [ ] Calcular un crédito con sistema francés.
- [ ] Cambiar a sistema alemán, americano y balloon.
- [ ] Modificar TRe, seguro de desgravamen, cesantía y otros seguros.
- [ ] Verificar que el cronograma muestre capital, interés, cargos, seguros y saldo.
- [ ] Verificar el dictamen de consistencia del plan.
- [ ] Probar abono extraordinario y fechas.
- [ ] Descargar el archivo Excel compatible.
- [ ] Usar Imprimir y elegir “Guardar como PDF”.

## Capacidad de pagos
- [ ] Abrir capacidad de pagos de forma independiente e introducir los datos manualmente.
- [ ] Evaluar escenarios que den viable, observado y no viable.
- [ ] Verificar ingresos, gastos, deudas, margen, endeudamiento y cuota máxima orientativa.
- [ ] Desde el plan, usar “Enviar plan de pagos a capacidad de pagos”.
- [ ] Confirmar que se transfiere la cuota y que los módulos siguen siendo independientes.
- [ ] Descargar Excel compatible y guardar el reporte como PDF.

## Historial y parámetros
- [ ] Guardar una simulación y verla en Historial.
- [ ] Eliminar un registro y borrar el historial.
- [ ] Modificar parámetros y verificar que se reflejen en los valores predeterminados.
- [ ] Cerrar sesión y confirmar que las vistas privadas quedan bloqueadas.
